# Experiment card

*One change, tested on a few teams for a fixed time, with a result decided in advance that would make
you stop. Fill in every line before you start. If a line cannot be filled in, the experiment is not
ready yet.*

| | |
|---|---|
| **The question** | *What do you want to find out? One sentence, ending in a question mark.* |
| **The change** | *What will be different, precisely enough that someone could check it is happening.* |
| **Why we think it may help** | *The finding or reasoning behind it, and how sure you are.* |
| **Teams in** | *Which teams make the change.* |
| **Teams for comparison** | *Which similar teams do not. Without a comparison, any change is hard to read.* |
| **Time box** | *Start date, end date. Usually four to eight weeks.* |
| **Baseline** | *The numbers before the start, for teams in and teams for comparison.* |
| **What we will measure** | *Two to four measures, the same ones as the baseline. Teams only, never individuals.* |
| **What would make us stop early** | *A result that means it is doing harm, e.g. change failure rate rises, or the team asks to stop.* |
| **What counts as "it worked"** | *Decided now, not afterwards. A threshold discussed after the result is a negotiation.* |
| **What the teams think** | *How you will ask them, at the middle and at the end.* |
| **Who has to say yes** | *To start: … To keep it after the time box: … Name the role, not only the person.* |
| **Decision at the end** | *Keep · change and run again · stop. Recorded with the date and who decided.* |
