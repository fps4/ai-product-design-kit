# The downloads, by part

Every item is a Markdown source. **Blank** is the version you fill in for your own case; **filled in**
(`*.claims.md`) shows it done for the running case — a fictional insurer fast-tracking small property
claims, with synthetic numbers. The PDF, DOCX, XLSX and PPTX on the site are built from these files.
The number in brackets is the item's number in the storyline.
